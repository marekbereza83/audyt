# Android & iOS

Android and iOS are supported via the AR Foundation Platform Support component included in the Core Unity package. There is no need to download or install additional packages for these platforms. The [Getting started tutorial](../../tutorial/) and our [Samples](../../samplescenes/) use these platforms by default.
